# BooksCollector — тесты

Проект содержит pytest-тесты для класса `BooksCollector`.

## Реализованные проверки

- добавление книг с допустимой длиной названия;
- отклонение пустого и слишком длинного названия;
- запрет повторного добавления книги;
- отсутствие жанра у новой книги;
- установка и получение допустимых жанров;
- отклонение неизвестной книги или жанра;
- получение книг заданного жанра и всего словаря книг;
- исключение возрастных жанров из списка детских книг;
- добавление книги в избранное только один раз;
- удаление и получение списка избранных книг.

Граничные длины названия, доступные жанры и сценарии отказа
проверяются с помощью параметризации.

## Запуск

```bash
pytest -v tests.py
```
