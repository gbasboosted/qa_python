# Sprint_7 — API-тесты Яндекс Самоката

Проект содержит независимые API-тесты на `pytest` для основного и
дополнительного задания с Allure-разметкой.

## Покрытие

- создание, логин и удаление курьера;
- создание заказа с BLACK, GREY, обоими цветами и без цвета;
- получение списка заказов;
- принятие заказа;
- получение заказа по его track-номеру.

Каждый тест создаёт собственные данные. Фикстуры удаляют курьеров и отменяют
заказы после выполнения сценария. Результаты ручной проверки описаны в
`manual_api_results.md`, а импортируемая коллекция лежит в каталоге `postman`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
```

Результаты для Allure сохраняются в `allure_results`. Для просмотра локально:

```bash
allure serve allure_results
```
