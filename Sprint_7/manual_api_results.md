# Результаты ручной проверки API

Проверка выполнена 15 сентября 2026 года на стенде
`https://qa-scooter.praktikum-services.ru`. Готовая Postman-коллекция находится
в каталоге `postman`.

| Сценарий | Фактический результат |
|---|---|
| Создание уникального курьера | 201, `{"ok": true}` |
| Повторное создание того же курьера | 409, сообщение о занятом логине |
| Создание без login / password | 400, сообщение о недостатке данных |
| Создание без firstName | 201 — расхождение с документацией |
| Успешный логин | 200, тело содержит числовой `id` |
| Неверный логин или пароль | 404, учётная запись не найдена |
| Логин без login | 400, сообщение о недостатке данных |
| Логин без password | стенд не отвечает до клиентского тайм-аута |
| Удаление существующего курьера | 200, `{"ok": true}` |
| Удаление несуществующего курьера | 404, курьера нет |
| Удаление без id | 404, `Not Found.` — документация обещает 400 |
| Создание заказа с BLACK | 201, тело содержит `track` |
| Создание заказа с GREY | 201, тело содержит `track` |
| Создание заказа с BLACK и GREY | 201, тело содержит `track` |
| Создание заказа без color | 201, тело содержит `track` |
| Список заказов | 200, `orders` — список |
| Получение существующего заказа по track | 200, тело содержит `order` |
| Получение без track | 400, сообщение о недостатке данных |
| Получение по несуществующему track | 404, заказ не найден |
| Принятие заказа | 200, `{"ok": true}` |
| Принятие без courierId | 400, сообщение о недостатке данных |
| Принятие с неверным courierId | 404, курьера не существует |
| Принятие без id заказа | 404, `Not Found.` |
| Принятие с неверным id заказа | 404, заказа не существует |

Для очистки созданных при проверке данных использованы отмена заказа через
query-параметр `track` и удаление курьера по его id. Для принятия заказа
`courierId` также передаётся как query-параметр.
