# Sprint_5 — автотесты Stellar Burgers

Проект содержит UI-автотесты учебного сервиса
[Stellar Burgers](https://stellarburgers.education-services.ru/) на Python,
Selenium и pytest.

## Что проверяется

- успешная регистрация и ошибка для пароля короче шести символов;
- вход с главной страницы, из личного кабинета, формы регистрации и формы
  восстановления пароля;
- переход в личный кабинет;
- переход из личного кабинета в конструктор по ссылке и логотипу;
- выход из аккаунта;
- переключение разделов конструктора «Булки», «Соусы» и «Начинки».

Каждый тест использует отдельный экземпляр браузера. После теста фикстура
обязательно вызывает `driver.quit()`.

## Структура проекта

- `tests/` — тесты, сгруппированные по функциональности;
- `conftest.py` — все pytest-фикстуры и подготовка тестового пользователя;
- `locators.py` — локаторы элементов с поясняющими комментариями;
- `generators.py` — генераторы уникального email и валидного пароля;
- `helpers.py` — общие Selenium-действия;
- `urls.py` — адреса страниц приложения;
- `requirements.txt` — зависимости проекта.

## Установка

Нужны Python 3.10 или новее и Google Chrome. Firefox поддерживается как
дополнительный браузер.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Selenium Manager автоматически подбирает драйвер для установленного браузера.

## Запуск

По умолчанию тесты запускаются в Google Chrome в фоновом режиме:

```bash
pytest -v
```

Запуск Chrome с видимым окном:

```bash
HEADLESS=0 pytest -v
```

Запуск в Firefox:

```bash
BROWSER=firefox pytest -v
```
