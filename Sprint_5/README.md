# Проект Sprint_5: автотесты сервиса Stellar Burgers

Проект содержит автоматизированные проверки пользовательского интерфейса
учебного сервиса [Stellar Burgers](https://stellarburgers.education-services.ru/).
Тесты написаны на Python с использованием Selenium и pytest.

## Что проверяется

- успешная регистрация и сообщение об ошибке для пароля короче шести символов;
- вход с главной страницы, из личного кабинета, формы регистрации и формы
  восстановления пароля;
- переход в личный кабинет;
- переход из личного кабинета в конструктор по ссылке и логотипу;
- выход из аккаунта;
- переключение разделов конструктора «Булки», «Соусы» и «Начинки».

Каждый тест использует отдельный экземпляр браузера. После теста фикстура
обязательно вызывает `driver.quit()`.

## Структура проекта

- `tests/` — тесты, сгруппированные по функциональности;
- `conftest.py` — все фикстуры pytest и подготовка тестового пользователя;
- `locators.py` — локаторы элементов с поясняющими комментариями;
- `generators.py` — генераторы уникального адреса электронной почты и
  корректного пароля;
- `helpers.py` — общие действия Selenium;
- `urls.py` — адреса страниц приложения;
- `requirements.txt` — зависимости проекта.

## Установка

Нужны Python 3.10 или новее и Google Chrome. Firefox поддерживается как
дополнительный браузер.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Диспетчер Selenium автоматически подбирает драйвер для установленного браузера.

## Запуск

По умолчанию тесты запускаются в Google Chrome без отображения окна браузера:

```bash
pytest -v
```

Запуск Google Chrome с видимым окном:

```bash
HEADLESS=0 pytest -v
```

Запуск в Mozilla Firefox:

```bash
BROWSER=firefox pytest -v
```
